# KH-Days-Recoded-Launcher-Patch
This is an app that patches the KH 1.5 + 2.5 Launcher and has it call a proxy application that launches the 358/2 Days native pc port (with support for Recoded, when its released).

NOTE: this is based off of the Launcher executable from Melon Mix (https://github.com/vitor251093/KHMelonMix). It has been looked over to create a patch to utilizes the changes that were done but adjusts what is called when days (or recoded) is selected.
